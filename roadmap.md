# JobConnect roadmap

## Done
- Database: roles, profiles, candidate profiles, companies, jobs, applications, saved jobs (all secured), seed data (6 companies, 12 jobs)
- Email/password sign-in, register, forgot/reset password, role-based areas
- Public site: home, job search with filters + pagination, job detail, companies, about
- Candidate dashboard: overview, profile, applications, saved jobs, resume upload, settings
- Apply flow with resume upload and duplicate prevention
- Employer dashboard: overview, company profile, post job, manage jobs (publish/unpublish/edit/delete), applications with status updates and interview details, settings
- Admin area: users, jobs (remove), applications

## Next
- End-to-end testing of all flows
- README, setup and API documentation

## Blocked
- Email notifications (application confirmation, new application, status change): needs a sending domain you own to be set up
